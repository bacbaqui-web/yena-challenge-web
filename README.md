# 예나의 도전

모바일 집밥 · 금주 포인트 달력입니다.

**실행 주소:** https://bacbaqui-web.github.io/yena-challenge-web/

로그인 없이 주소를 열면 바로 사용할 수 있는 공개 공동 달력입니다. 어느 기기에서든 같은 기록과 포인트가 표시됩니다. 주소를 아는 사람은 기록을 보고 수정할 수 있습니다.

이 저장소는 GitHub Pages 배포용 화면과 캐릭터 이미지입니다. 기록은 공개 API를 통해 별도의 비공개 GitHub 저장소에 저장됩니다. GitHub 인증 토큰은 서버에서만 사용하며 이 공개 저장소에 포함하지 않습니다.
